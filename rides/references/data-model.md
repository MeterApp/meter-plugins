# Meter data model (public DTOs)

Generated from the `@meterapp/meter-sdk` DTO schemas; do not edit by hand. Every Meter Rides tool result is validated against one of these objects before it leaves the server, so a field that is not listed here is never returned. Money is in minor currency units (`*_minor`), distances in meters, durations in seconds, timestamps ISO 8601. `Visible to` narrows a field to certain viewers; everyone else gets null or no field.
